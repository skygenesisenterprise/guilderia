# Privacy Policy

d.js toolkit (1091287989151342622) processes message content of all messages sent in channels the app can view to:

- provide on-demand autoresponse functionality to decrease the necessity for helpers to provide repetitive answers.
- hide intrusive link embeds to the discord developers documentation

The application does not persist user data or make it available to third parties.
The developer may employ temporary debug logs as need arises.
